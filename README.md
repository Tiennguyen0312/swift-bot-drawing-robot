
## 🥇 I worked on features that allow the SwiftBot to:
- Capture and decode QR codes using the onboard camera
- Read and validate geometric shape instructions
- Identify supported shapes such as squares, rectangles and triangles
- Calculate dimensions, perimeter and required turning angles
- Control the robot's movement and turning behaviour
- Adjust movement according to the selected shape
- Use SwiftBot underlights and buttons during interaction
- Record information about completed drawing tasks
  
## 🤖 SwiftBot Features
- QR Code Processing captures QR codes through the SwiftBot camera and extracts shape information.
- Shape Validation:checks whether the provided dimensions form a valid supported shape.
- Shape Drawing: controls robot movement to draw squares, rectangles and triangles.
- Geometry & Trigonometry:calculates distances, perimeter and triangle angles required for robot movement.
- Robot Control: manages movement speed, direction, turning and stopping through the SwiftBot API.
- User Interaction: uses SwiftBot buttons and LED underlights as part of the application flow.
- Task Recording: records information such as completed shapes, drawing duration and calculated measurements.
